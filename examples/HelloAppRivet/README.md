# HelloAppRivet

Original SwiftUI starter generated by AppRivet. Bundle ID: org.example.helloapprivet.

On a Mac with full Xcode and iOS Simulator support:

    apprivet doctor
    apprivet build --trust-project
    xcrun simctl list devices available
    apprivet test --trust-project --simulator SIMULATOR_UDID

Build/test executes project-controlled code. Use trusted source and a Mac account without sensitive signing credentials. The generated scheme includes a unit test target. Windows/Linux can prepare this project; iOS compilation runs on a Mac. Remote execution is not yet available.

For physical devices, open HelloAppRivet.xcodeproj in Xcode and use Apple's official signing and device workflows. AppRivet Milestone 1 does not sign, install, launch, or publish device builds. Set a unique bundle ID and team in Xcode before signing. No Apple SDK or credentials are included.
