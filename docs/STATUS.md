## Review and decisions

Independent read-only review found two important defects, both fixed with failing-then-passing regression tests:

1. Generated names such as class and SwiftUI could conflict with Swift syntax/modules. Explicit AppRivet_<Name> module names now match test imports. Eventual Mac CI includes the framework-name case; live compilation is still unverified.
2. Unix children could survive an exited parent even without escaping its process group. Cleanup now terminates the owned group on every completion path. Linux reproduction failed for both open/closed stdout before the fix; all four exit/cancel/timeout cases passed after it.

No deferred minor review findings. Reviewer declined live Apple compatibility (unavailable hardware), Unix runtime proof (subsequently supplied by Linux tests), and future signing/remote/release capabilities (outside M1). These remain distinct from verified behavior.
