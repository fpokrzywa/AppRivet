# AppRivet Milestone 1 Implementation Plan

Execution: native implementation in this session using the executing-plans and test-driven-development skills. The user's explicit request authorizes routine decisions and continuous implementation without a design approval pause. The empty dedicated workspace is the new repository, not an existing application's worktree.

Goal: deliver portable diagnostics, safe SwiftUI project creation, passive inspection and a testable Mac simulator adapter.

Architecture: CLI separates project, doctor, build and process-runner packages. Use embedded original templates and standard library only. Spec: [PRD](../../PRD.md), [architecture](../../ARCHITECTURE.md).

Global constraints: no Apple passwords; no Xtool code/dependency; no SDK redistribution; no license selection; signing and remote execution remain planned; preserve JSON errors; test actual features and state hardware gaps.

Review focus: traversal and Windows reserved names; unexpected project layouts; tool absence and timeout; arbitrary scripts versus credentials; false claims from mocked builds.
